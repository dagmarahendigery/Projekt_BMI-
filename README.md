# AUTOMATYZACJA TESTÓW APLIKACJI WEBOWEJ W PYTHONIE

Projekt automatyzacji testów aplikacji webowej napisany w Pythonie z wykorzystaniem Selenium WebDriver oraz frameworka Pytest.

---

# Cel projektu

Celem projektu jest przetestowanie najważniejszych funkcjonalności serwisu:

https://diety.nfz.gov.pl

Zakres testów obejmuje:

1. Wyliczenie BMI dla użytkownika niezalogowanego
2. Walidację formularza BMI
3. Rejestrację użytkownika
4. Walidację formularza rejestracji
5. Logowanie użytkownika
6. Funkcjonalność „Show Password”
7. Wybór planu żywieniowego przez zalogowanego użytkownika
8. Przejście do przepisów
9. Wylogowanie użytkownika

Projekt został wykonany zgodnie z:

- wzorcem projektowym Page Object Model (POM),
- podejściem Data Driven Testing,
- frameworkiem Pytest.

---

# Technologie

Projekt wykorzystuje:

- Python 3.12
- Selenium WebDriver
- Pytest
- Faker
- Chromium / ChromeDriver
- Pytest HTML Report
